## 요구사항
- 로또 번호의 범위는 1~45, 중복되지 않는 숫자 6개  
- 당첨 번호는 중복되지 않는 숫자 6개와 보너스 번호 1개  
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원

- 로또 1장에 1,000원
- 사용자가 입력한 가격에 맞게 로또를 구매하고, 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력한다.  
- 입력은 로또 구입 금액, 당첨 번호, 보너스 번호를 입력받는다.( ex) `14000\n1,2,3,4,5,6\n7`)  
- 출력은 발행한 로또 수량 미 번호를 출력(로또 번호는 오름차순으로)  
- 그리고 당첨 내역을 출력하고, 수익률을 출력한다.
### 출력 형식
```kotlin
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

3개 일치 (5,000원) - 1개
        4개 일치 (50,000원) - 0개
        5개 일치 (1,500,000원) - 0개
        5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개

        총 수익률은 62.5%입니다.
```
- 예외 상황 시 에러 문구를 출력(에러 문구는 "[ERROR]"로 시작해야함)
```kotlin
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
```
## 구현할 기능 목록
- [ ] 입력 받는 기능
- [ ] 입력을 파싱해주는 기능
- [ ] 입력이 올바른지 검사하는 기능
  - 금액은 1,000원 단위
  - 당첨 번호는 ,로 분리된 6개
  - 보너스 번호는 1~45사이의 숫자
  - 모든 번호는 중복되면 안됨 
- [ ] 금액에 맞게 로또를 구매하는 기능
- [ ] 로또(랜덤넘버 6개)를 뽑는 기능
- [ ] 구매한 로또가 몇등인지 확인하는 기능
- [ ] 당첨된 결과를 출력하는 기능
- [ ] 수익률을 계산하는 기능
